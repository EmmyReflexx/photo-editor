# 📸 Rex Photo Editor

> My first real JavaScript project - built during my first month of coding.

A browser-based photo editor that lets you upload, edit, and export images with real-time filters and effects.

## ✨ Live Demo


## 🎯 Features

### Working Features ✅

- **Image Upload** - Drag & drop or browse from device
- **Photo Editing** - Adjust brightness, contrast, and saturation in real-time
- **Dark/Light Theme** - Toggle between themes with localStorage persistence
- **Export Options** - Save as JPEG, PNG, or WebP with adjustable quality (0-100%)
- **Undo/Redo** - History stack for filter adjustments
- **Reset All** - One-click reset to original image

## 🛠️ Built With

- **Vanilla JavaScript (ES6+)** - No frameworks, just pure JS
- **HTML5 Canvas API** - For image export with filters applied
- **CSS3** - Custom properties, animations, and responsive design
- **CSS Grid & Flexbox** - Responsive layout.
